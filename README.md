# GroundGuard - Smart Earthing Health Monitoring System

## Project Overview

GroundGuard is an ESP32-based smart earthing health monitoring system designed to monitor voltage, leakage/current, and moisture-related parameters.

## Hardware Components

- ESP32 Development Board
- Voltage Input/Sensor
- Leakage/Current Input
- Moisture Sensor
- 0.96-inch SSD1306 OLED
- Green LED
- Buzzer
- Breadboard
- Jumper Wires

## Features

- Multi-parameter monitoring
- Health-score calculation
- HEALTHY, WARNING and CRITICAL classification
- OLED status display
- LED indication
- Audible buzzer alert
- Wokwi simulation support

## System Status

| Health Score | Status |
|---|---|
| 90 and above | HEALTHY |
| 60-89 | WARNING |
| Below 60 | CRITICAL |
